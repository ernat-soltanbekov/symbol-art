# symbol-art

`symbol-art` — консольная программа на Go, которая принимает строку и выводит её в виде ASCII-арта с использованием banner-файлов.

Программа поддерживает:
- буквы
- цифры
- пробелы
- специальные символы
- последовательность `\n` для переноса строк

Дополнительно реализованы:
- анализ текста через флаг `--analyze`
- рекомендации через флаг `--suggest`

## Возможности

- преобразование текста в ASCII-арт
- поддержка нескольких шрифтов
- корректная обработка пустой строки
- корректная обработка переводов строки `\n`
- анализ входной строки
- вывод рекомендаций по улучшению текста

## Поддерживаемые шрифты

- `standard`
- `shadow`
- `thinkertoy`

## Как запустить

### Обычный запуск

```bash
go run . "Hello"
```

### Запуск с выбором шрифта

```bash
go run . "Hello" standard
go run . "Hello" shadow
go run . "Hello" thinkertoy
```

### Перенос строк

```bash
go run . "Hello\nWorld"
```

### Анализ текста

```bash
go run . "Hello World" --analyze
```

### Рекомендации

```bash
go run . "hello" --suggest
```

### Несколько параметров вместе

```bash
go run . "Hello World" shadow --analyze --suggest
```

## Поддерживаемые аргументы

- `standard` — стандартный шрифт
- `shadow` — альтернативный шрифт
- `thinkertoy` — альтернативный шрифт
- `--analyze` — выполнить анализ входной строки
- `--suggest` — вывести рекомендации

## Что делает `--analyze`

После вывода ASCII-арта программа показывает:

- количество заглавных букв
- количество строчных букв
- количество цифр
- количество специальных символов
- количество пробелов
- наличие смешанного регистра
- повторяющиеся символы
- числовые последовательности
- оценка сложности текста
- размеры итогового ASCII-арта

## Что делает `--suggest`

Флаг `--suggest` выводит текстовые рекомендации по входной строке. Например:

- использование верхнего регистра
- наличие повторяющихся пробелов
- оценка размеров выходного ASCII-арта

## Особенности обработки

- пустая строка `""` не выводит ничего
- `"\n"` выводит одну пустую строку
- несколько `\n` подряд создают несколько переводов строки
- строка из пробелов рендерится как ASCII-арт пробелов

## Примеры

```bash
go run . "Hello"
go run . "Hello\nThere"
go run . "Helloo 123" --analyze
go run . "hello" --suggest
go run . "Hi" shadow --analyze
```

## Makefile

Для часто используемых команд предусмотрен `Makefile`.

Показать доступные команды:

```bash
make help
```

Запустить программу с произвольным текстом:

```bash
make run TEXT="Hello, very best auditor"
```

Запустить демонстрацию рекомендаций:

```bash
make suggest
```

Запустить демонстрацию анализа:

```bash
make analyze
```

Запустить полную демонстрацию с анализом и рекомендациями:

```bash
make audit
```

Собрать программу:

```bash
make build
```

## Тестирование

Запустить все тесты:

```bash
go test ./...
```

или:

```bash
make test
```

Запустить тесты с подробным выводом:

```bash
make test-verbose
```

Запустить только golden-тесты:

```bash
make golden
```

## Golden-тесты

Golden-тесты проверяют итоговый вывод всей программы: команда из `samples/input*.txt` выполняется, а полученный результат сравнивается с соответствующим ожидаемым результатом из `samples/output*.txt`.

Это позволяет проверить работу программы целиком, включая:

- разбор аргументов
- выбор шрифта
- обработку `\n`
- генерацию ASCII-арта
- `--analyze`
- `--suggest`
- итоговый формат вывода

## Назначение файлов

- `main.go` — точка входа программы и обработка аргументов командной строки
- `main_test.go` — golden-тесты основной программы
- `internal/banner` — чтение banner-файлов и построение ASCII-арта
- `internal/printer` — вывод готового ASCII-арта
- `internal/analyzer` — анализ текста
- `internal/suggest` — рекомендации по тексту
- `samples/` — примеры входных и ожидаемых выходных данных
- `Makefile` — удобные команды для сборки, запуска и тестирования проекта
